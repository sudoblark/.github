# .github

Sudoblark's organisation-wide GitHub defaults:

- `profile/README.md` is the profile on [github.com/sudoblark](https://github.com/sudoblark).
- `.github/pull_request_template.md` is the default pull request template for any repo in the organisation that doesn't have its own.

Managed by `sudoblark.terraform.github`, which also writes `docs/CODEOWNERS`.
