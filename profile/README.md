# Sudoblark

Sudoblark is the consultancy of [Ben Clark](https://github.com/benjaminlukeclark), a UK-based Principal Consultant. Ben puts AI safely into the systems you already run, backed by over a decade of enterprise software. He also rescues stalled programmes and launches new products.

## Public repos

- [`sudoblark.ai.sdlc-hackathon`](https://github.com/sudoblark/sudoblark.ai.sdlc-hackathon): the starter repo for Ben's [LLMs in the SDLC hackathon](https://sudoblark.com/talks/llms-in-the-sdlc/), with agent skills that log and work tickets one commit at a time
- [`sudoblark.ai.sdlc-hackathon-dungeon-explorer`](https://github.com/sudoblark/sudoblark.ai.sdlc-hackathon-dungeon-explorer): an ASCII dungeon explorer built in two hours from that starter repo, as a worked example
- [`sudoblark.monsternames.api`](https://github.com/sudoblark/sudoblark.monsternames.api): a serverless REST API, deployed with [data-driven Terraform](https://sudoblark.com/patterns/data-driven-terraform/) and GitHub Actions
